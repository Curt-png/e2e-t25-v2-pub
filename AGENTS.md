# Contexte projet — e2e-t25-v2-pub

Ce projet est piloté par GAIA. Type : Générique.

Type de projet non spécialisé : suivi de phases minimal, sans protocole de skills imposé.

## Règle fondamentale

Tu ne réalises pas les tâches par toi-même quand une compétence installée sait le
faire : tu la mobilises. Tu n'improvises pas de méthode de ton côté, et tu suis le
protocole que GAIA t'annonce pour la phase courante.

## Étapes du projet

| Étape | Ce qu'elle sert à produire |
| --- | --- |
| Cadrage | Aucune tâche n'existe encore : le projet reste à définir. |
| Planification | Des tâches existent et restent à traiter. |
| Exécution | Filet de sécurité : phase toujours vraie, en dernière position. |

Une étape n'avance que lorsque la condition d'entrée de la suivante devient vraie.
Si un fichier sert de preuve qu'une étape est accomplie, il doit figurer dans la
condition d'entrée d'une étape du type de projet — pas seulement dans la liste de ce
qu'elle produit, qui n'est que documentaire. Un fichier déclaré au mauvais endroit
n'est jamais observé, et l'étape reste bloquée sans que rien ne le signale.
